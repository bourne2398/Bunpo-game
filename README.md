# 文をつくろう (Bunpo Game)

Mobile-first JLPT sentence arrangement quiz.

## Features
- Drag & drop words (follows your finger)
- 3 lives
- 2-minute timer
- Points per question
- Hana Maru (花丸) animation on perfect score
- Score history (localStorage)
- PWA installable

## Play
Open `index.html` on your phone or enable GitHub Pages.

Repo: https://github.com/bourne2398/Bunpo-game
